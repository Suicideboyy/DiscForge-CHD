DiscForge CHD 2.2.0

- CPU and I/O indicators now measure DiscForge CHD and its encoder/extractor processes.
- Safe multi-track BIN sets without CUE can be encoded with a generated temporary CUE. Sources are kept when original pregap/index details cannot be recovered.
- Different game revisions no longer collide or count as the same converted output.
- Stop Now cancels the active child process, cleans this task's temporary files and preserves sources.
- Last input folder is remembered; a newly selected input defaults to its optimized output folder.
- Codecs are selected with explained checkboxes; custom chdman and 7-Zip tools can be chosen in Settings.
- PlayStation 1 covers use xlenore/psx-covers. Updated colors, icons and transitions.

Download DiscForge-CHD-2.2.0-win-x64.zip, extract the entire archive and run DiscForge-CHD.exe. Keep all folders together. .NET 10 and Windows App SDK are included. Windows 10 2004+ x64 is required. WebView2 Runtime powers the cover panel. The source ZIP contains the complete project.
