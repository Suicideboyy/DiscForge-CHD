# Componentes de terceiros

DiscForge CHD 2.5.0. Capas de PS1 podem usar [Libretro thumbnails](https://github.com/libretro-thumbnails/Sony_-_PlayStation) como reserva online; imagens não são distribuídas no pacote.

[English](../../THIRD-PARTY.md)

O aplicativo distribui .NET, Windows App SDK, WebView2, SharpCompress e chdman/MAME conforme as licenças de cada projeto. As licenças originais ficam na pasta `licenses` do pacote e devem ser mantidas junto ao aplicativo. Capas de jogos são consultadas nos projetos xlenore/ps2-covers e xlenore/psx-covers. Veja [THIRD-PARTY.md](../../THIRD-PARTY.md) para atribuições e links completos.
