# Apresentação do DiscForge CHD

- [PowerPoint editável](DiscForge-CHD-apresentacao.pptx): 22 slides, com fontes nas notas.
- [PDF para leitura](DiscForge-CHD-apresentacao.pdf): reprodução visual dos slides.

Base: código e documentação da revisão [34a44a1](https://github.com/Suicideboyy/DiscForge-CHD/tree/34a44a1), versão 1.2.1, consultados em 21/09/2026.

O material cobre produto, funcionalidades, arquitetura, fluxos, casos de uso, stories e critérios de aceitação, requisitos, gestão ágil, backlog, métricas, riscos, roadmap, QA, publicação e manutenção. Diferencia recursos implementados, personas inferidas e propostas. Não apresenta sugestões como funcionalidades existentes.

Os resultados de testes vêm de `TESTES.txt`; os testes do aplicativo não foram reexecutados para esta documentação. A retomada usa `chdman info`, enquanto novas saídas passam por `verify`. O projeto publica por script local e não possui workflow de CI na revisão analisada.

Para atualizar: editar o PPTX no PowerPoint/LibreOffice, conferir as fontes e exportar novamente o PDF. O PDF é uma cópia visual rasterizada; use o PPTX para editar ou copiar conteúdo. Publicar alterações de documentação por commit próprio: a lista explícita de `Publicar.ps1` não inclui `docs/`.
